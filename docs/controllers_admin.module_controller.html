Module: controller

Controlador para las rutas de administración de películas en el frontend. Comunica con la API para gestionar películas mediante fetch y maneja vistas EJS. Utiliza node-fetch para solicitudes HTTP y form-data para envíos con archivos. Cada función maneja errores y redirecciones según sea necesario.
