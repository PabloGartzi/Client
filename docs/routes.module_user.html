Module: user

Rutas del usuario para el frontend. Incluye rutas para el dashboard del usuario, búsqueda de películas, gestión de favoritos y recuperación de contraseña. Utiliza controladores definidos en user.controller.js para manejar la lógica de cada ruta. Utiliza middleware de autenticación y autorización para proteger las rutas.
